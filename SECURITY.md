# Security policy

## Supported versions

Security fixes are applied to the latest released version. This project does not currently maintain older release branches.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not open a public issue for an undisclosed vulnerability and do not include real secrets or sensitive repository contents in a report.

You can expect an initial acknowledgement within seven days. Timelines for validation and a fix depend on severity and complexity. If a report is accepted, the project will coordinate disclosure after a fix is available. If it is declined, the response will explain why.

Repo Doctor uses filename and lightweight content checks. Its output is guidance, not a security audit or a guarantee that a repository is safe.
